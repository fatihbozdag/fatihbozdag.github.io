# fatihbozdag.com

Personal academic website of Fatih Ünal Bozdağ, built with [Quarto](https://quarto.org) and deployed to GitHub Pages by GitHub Actions on every push to `main`.

- Edit `*.qmd` files; the site rebuilds automatically.
- Publications: `publications.qmd` (hand-formatted APA) and `pubs/bozdag.bib`.
- Open-access PDFs live in `files/papers/`.
- Custom domain: `CNAME`.

Local preview (optional): install Quarto, then `quarto preview`.
